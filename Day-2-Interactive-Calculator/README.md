## 📖 Project Overview

SkillCalc is more than a simple calculator. It demonstrates core JavaScript concepts through a practical application while maintaining a clean and responsive user interface.

The calculator supports arithmetic operations, dynamic DOM updates, responsive layouts, CSS animations, JavaScript runtime demonstrations, and various JavaScript function types.
