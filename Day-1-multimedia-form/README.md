# 🚀 SKILLSEC | Responsive Multimedia Form Page

### Learn • Build • Grow

---

## 📌 About The Project

**SKILLSEC** is a responsive educational platform interface built as part of my **FullStack 12 Day Challenge**.

The project provides a modern user experience where users can explore courses, register, interact with multimedia content, and experience responsive layouts across different devices.

This project combines HTML, CSS, and JavaScript concepts into a single practical application.

---

## ✨ Features

* Multi-field Registration Form
* Sign In / Sign Up Interface
* JavaScript Form Validation
* Responsive Navigation Bar
* Embedded Google Maps using iframe
* Audio Integration
* Video Integration
* Responsive Flexbox and Grid Layout
* Hover Effects and Animations
* Mobile Friendly Design
* Dynamic Console Outputs
